# 🌱 PruebaDeepsAGRO

Página web desarrollada como prueba de diseño e implementación de una interfaz web.

## 📌 Descripción

Este repositorio contiene una página web desarrollada en HTML, orientada a la presentación visual de una interfaz relacionada con el proyecto DeepsAGRO.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página web.
- **CSS3:** estilos y presentación visual, si están implementados en el proyecto.
- **JavaScript:** interactividad, si está implementada en el proyecto.

## 🚀 Visualización

1. Descarga o clona este repositorio.
